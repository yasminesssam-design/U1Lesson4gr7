تثبيت البرامجInstalling Programs

أثناء تنفيذ مشروع قد تحتاج إلى برامج، فإذا لم تكن متوفرة في نظام التشغيل يمكنك الحصول عليها وتثبيتها على جهازك.

اسم برنامج التثبيت عادة يسمَّى "Setup" أو "Setup.exe".

عملية التثبيت تعتمد على الهيئة التي يأتي عليها البرنامج:

  1. شراء البرنامج، ويأتي على قرص مضغوط (CD) أو قرص DVD، ويُستخدم هذا القرص لتثبيت البرنامج.
  2. تنزيل البرنامج عبر الإنترنت، ويكون على هيئة ملف يُستخدم لتثبيت البرنامج.

خطوات تثبيت البرنامج من قرص مضغوط أو قرص DVD

  1. إدخال قرص البرنامج في محرك الأقراص بجهاز الكمبيوتر، فيظهر مربع حوار «التشغيل التلقائي».
  2. اختيار "Run Setup.exe".
  3. اتباع تعليمات التثبيت التي يوفرها البرنامج.
💡 خطوات التثبيت تختلف من برنامج لآخر.
نشاط 1 تعرَّف البرامج المثبَّتة على جهاز الكمبيوتر.

خطوات تثبيت البرنامج من ملف تم تنزيله من الإنترنت

  1. استخدام أيقونة جهاز الكمبيوتر "This PC" للوصول إلى الملف الذي تم تنزيله.
  2. النقر مزدوجًا (الضغط مرتين) فوق الملف؛ ليبدأ عمل برنامج التثبيت.
💡 الملف الذي قمت بتنزيله قد يكون ملفًّا أو ملفات مضغوطة؛ لذلك عليك أولًا فك الملف المضغوط؛ لكي تتمكن من التعامل معه.
نشاط 2 قم بتنزيل أحد البرامج المجانية للحماية من الفيروسات من خلال الإنترنت.

تثبيت البرنامج من ملف مضغوط

  1. فك ضغط الملف.
  2. النقر مزدوجًا فوق ملف التثبيت.
  3. اتباع تعليمات التثبيت التي يوفرها البرنامج.
نشاط 3 قم بتثبيت البرنامج أو البرامج التي قد تحتاجها في مشروعك.

To execute your project on a computer or mobile device, you must ensure that all required programs are installed on the device.

If the required programs are not installed, you can get them:

  1. From a storage device
  2. By downloading it from the internet

Then you can install the program to use it.

The installation of programs depends on the form in which the program comes:

  1. If you purchased the program: it comes on a CD or DVD, and this disc is used to install the program.
  2. If you downloaded the program from the internet: it will be in the form of a file, and this file is used to install the program.

First: Installing a program from a CD or DVD

  1. Insert the disc into your computer’s CD / DVD drive.
  2. An AutoPlay dialog box appears as shown.
  3. Click on Run SETUP.EXE, it is usually the name of the installation file.
  4. Follow the installation instructions.
📝 Note: Installation procedures differ from one program to another.

Second: Installing a program from an Internet-downloaded file

  1. Use the “This PC” icon to access the downloaded file.
  2. Double-clicking the file starts up the installer.
📝 Note: If the downloaded file is compressed, you need to unzip it first to access and select the SETUP.EXE icon.

How to install a program from a compressed file

  1. Extract the compressed files.
  2. Then double-click the installation file.
  3. Follow the installation instructions.

إلغاء (إزالة) تثبيت البرامجRemove or Uninstall a Program

يعني حذف كافة الملفات الخاصة بالبرنامج المراد إزالته من جهاز الكمبيوتر.

إذا توقفت عن استخدام برنامج، فعليك إزالته من جهازك. لماذا؟

  1. لتوفير مساحة تخزينية على القرص.
  2. لتسريع الجهاز وتسهيل استخدامه.

هناك طريقتان لإزالة أو إلغاء تثبيت البرنامج

  1. البرنامج نفسه يقوم بذلك؛ حيث تأتي العديد من البرامج مصحوبة بأمر إزالة التثبيت الخاص بها.
  2. من خلال لوحة التحكم (Control Panel) الخاصة بنظام التشغيل؛ حيث يساعدك نظام التشغيل في إلغاء تثبيت البرنامج.

خطوات إزالة برنامج مثبت على الجهاز

  1. فتح نافذة لوحة التحكم (Control Panel).
  2. النقر فوق Uninstall a program فتظهر نافذة البرامج المثبتة.
  3. النقر فوق البرنامج الذي تريد إلغاء تثبيته، ثم النقر فوق "Uninstall".
💡 عند التوقف عن استخدام أحد البرامج المثبتة على جهازك يُفضل إلغاء تثبيت هذا البرنامج. إزالة البرامج غير المستخدمة تؤدي إلى: توفير مساحة تخزينية على القرص وزيادة سرعة الجهاز وسهولة استخدامه.
نشاط 4 قم بفتح نافذة لوحة التحكم، وانتقل لمشاهدة البرامج المثبتة على جهاز الكمبيوتر، ثم قم بإلغاء تثبيت أحد البرامج (إذا كنت تريد) بالنقر فوق Uninstall.

If you stop using a program, you should uninstall it from your device. Why?

  1. To save disk storage space (free up space)
  2. To speed up and ease the use of the device

Uninstalling a program means that you delete all the files of the program from your device.

Two methods to uninstall a program

  1. Using the uninstallation command in the program — many programs come with their own uninstall command.
  2. Using the Control Panel — the operating system helps you uninstall the program through Control Panel.

Steps to uninstall a program

  1. Open the Control Panel window.
  2. Click on Uninstall a program; it displays the installed programs window.
  3. Click on the program you want to uninstall, then click Uninstall.

إعداد وتثبيت الأجهزة الملحقةInstalling a New Device (Plug and Play & Setup CD/DVD)

يدعم نظام التشغيل العديد من الأجهزة الملحقة بالكمبيوتر، مثل: الطابعة، كاميرا الويب، الماسح الضوئي؛ حيث يقوم بالتالي:

  • اكتشاف الجهاز الملحق الجديد تلقائيًّا.
  • تثبيت برنامج التشغيل (Driver) الصحيح والمناسب للجهاز الملحق؛ لاستخدامه بميزاته الكاملة.

تثبيت جهاز جديد

تتضمن بعض الأجهزة قرصًا مضغوطًا (CD) أو قرص DVD يحتوي على:

  • ملفات برامج التشغيل (Drivers)
  • برامج الأدوات المساعدة
يقوم برنامج الإعداد (Setup program) بشكل تلقائي بنسخ ملفات برنامج التشغيل (Driver) وملف معلومات الإعداد (inf.) داخل المجلد المخصص لذلك.

تثبيت جهاز له خاصية التوصيل والتشغيل [Plug and Play]

أنظمة التشغيل الحديثة تتضمن قائمة من برامج التشغيل (Drivers) للعديد من الأجهزة الملحقة.

عندما يتضمن نظام التشغيل برنامج تشغيل مطابقًا للجهاز الملحق الجديد:

  1. يكتشف نظام التشغيل الجهاز الملحق الجديد.
  2. يقوم نظام التشغيل بالبحث في قائمة برامج التشغيل التي لديه عن البرنامج المناسب لهذا الجهاز.
  3. إذا عثر نظام التشغيل على برنامج تشغيل مطابق للجهاز يقوم بتثبيت ملف البرنامج.
  4. يُجري نظام التشغيل التعديلات الضرورية دون الحاجة إلى تدخُّل المستخدم.

عندما لا يتضمن نظام التشغيل برنامج تشغيل مطابقًا للجهاز الملحق الجديد، فهناك طريقتان:

  1. يقوم نظام التشغيل بتشغيل برنامج المعالج؛ للعثور على برنامج التشغيل الخاص بالجهاز الملحق الجديد.
  2. تحديد مكان وجود برنامج التشغيل للجهاز الملحق الجديد، الذي قد يكون على قرص ضوئي أو إحدى وحدات التخزين الأخرى.
نشاط 6 هل المشروع الذي تقوم بإعداده وتجهيزه له يحتاج إلى كاميرا ويب أو ماسح ضوئي، أو أي جهاز ملحق جديد تريد تركيبه على جهاز الكمبيوتر؟

Installing a new device

There are two ways: installing plug and play devices, and installing devices using setup CD/DVD.

1) Installing plug and play devices

  • Operating systems support many devices attached to the computer such as USB printers, webcams, scanners, etc.
  • Modern operating systems include a list of drivers for many peripheral devices.
  • When you connect a new plug and play device, the operating system automatically detects the new peripheral.
  • Then, it searches its list of drivers to find the appropriate driver.

If the operating system finds the matching driver:

  • It installs the correct driver file(s).
  • It makes other necessary adjustments to the system without any intervention from you.

If the operating system does not find the matching driver:

  • The operating system runs a wizard program to find the driver for the new peripheral.
  • The user must tell the wizard where to find the driver (on a CD, flash drive, or other storage device).

2) Installing non plug and play devices (using Setup CD/DVD)

Some devices come with a setup CD or DVD that includes:

  • Driver files
  • Utility programs
  • Information file (inf file)

When you insert the CD or DVD, the setup program automatically copies the driver files and the setup information file (inf.) into a dedicated folder to run the device.

تثبيت الطابعةExample: Installing a Printer

أولًا: تثبيت طابعة محلية تدعم خاصية التوصيل والتشغيل

🖨️ الطابعة المحلية: هي الطابعة المتصلة مباشرة بجهاز الكمبيوتر.

عند توصيل الطابعة بمنفذ USB تقوم خاصية التوصيل والتشغيل بعملية التثبيت تلقائيًّا.

ثانيًا: خطوات تثبيت طابعة لا تدعم خاصية التوصيل والتشغيل [Non-Plug and Play Printer]

  1. فتح نافذة لوحة التحكم (Control Panel).
  2. اختيار Hardware and Sound.
  3. اختيار "الأجهزة والطابعات" (Devices and Printers).
  1. الضغط فوق "إضافة طابعة" Add a printer.
  1. الضغط على "The printer that I want isn't listed".
  1. اختيار "Add a local printer or network printer with manual settings".
  1. لإكمال عملية الإعداد يجب تحديد المَنفَذ الذي تتصل به الطابعة:
    • معظم الطابعات القديمة تتصل بمَنفَذ متوازي تستخدم المَنفَذ LPT.
    • الطابعات الحديثة تستخدم المَنفَذ USB.
  1. النقر فوق "Next" بعد اختيار المَنفَذ.
  2. اختيار البرنامج المتوافق مع نوع الطابعة، من قائمة "الطابعات" (Printers) المتوافرة لقائمة "الشركة المصنِّعة" (Manufacturer).

إذا لم تجد برنامج التشغيل المطلوب:

  • يتم النقر فوق زر «قرص خاص» "Have Disk".
  • استعراض "Browse" وحدات التخزين للوصول إلى برنامج التشغيل المطلوب.

إذا لم يكن لديك برنامج لتعريف الطابعة، أو إذا كنت تريد أحدث إصدار:

  • يتم النقر فوق زر "Windows Update" لتحديث قائمة الطابعات.
  • بعد اكتمال التحديث يتم التحقق من القائمة مرة أخرى؛ لمعرفة إذا كان طراز الطابعة الخاصة بك أصبح متوافرًا.
  1. إعطاء اسم للطابعة. يتضمن الاسم الافتراضي عادة اسم الشركة المصنِّعة وطراز الطابعة، يمكن تغيير هذه القيمة إلى اسم أكثر وصفًا لاحقًا.
💡 بعد إتمام عملية تثبيت الطابعة بنجاح يوفر المعالج إمكانية طباعة صفحة اختبار؛ للتأكد من عمل الطابعة بشكل صحيح.
💡 إذا كانت حزمة تشغيل الطابعة تتضمن برنامج الإعداد قم بتشغيله، ومن خلاله يمكنك تعريف الطابعة داخل نظام التشغيل.
نشاط 5 كيف يمكنك معرفة الطابعات المُعرَّفة والمُثبَّتة على جهاز الكمبيوتر من خلال لوحة التحكُّم؟

First: Installing a plug and play local printer

🖨️ Local printer: a printer that is directly connected to the computer.
  1. Connect the printer to a USB port.
  2. The Plug and Play feature will automatically handle the installation.

Second: Installing a non-plug and play printer

This may require some additional setup steps:

Control Panel ⇒ Hardware and Sound ⇒ Devices and Printers

If the required printer is found, select it, then click “Add a printer”.

If the printer is NOT found, click “The printer that I want isn’t listed.”

Select “Add a local printer or network printer with manual settings.”

Identifying the printer connection port

  • For older printers: usually connect via a parallel port ⇒ use LPT1.
  • For modern printers: select USB port.

Identifying the correct driver

  • Click ‘Next’ to choose the appropriate driver.
  • From the list of drivers available in the Driver Store, you can choose the one that is compatible with your printer type.

If you do not find the required driver

  • Click on “Have Disk”.
  • Browse your storage devices for the driver you need.
  • If you do not have the driver or suspect a newer version is available, click on “Windows Update” to update the list of printers.
  • After the update is complete, check the list again to see if your printer model is now available.

Final step in printer setup

The last step is to name the printer. The default name usually includes the manufacturer name and model. You can change the name of the printer.

After the installation process is completed, the wizard may offer to print a test page to ensure the printer is working properly.

📝 Note: If the printer driver package includes a setup program, run the setup program to install the printer within the operating system.

أهم نقاط الدرس والمصطلحاتKey Points & Key Words

طرق تثبيت البرامج

  1. من قرص CD / DVD: إدخال القرص ← اختيار "Run Setup.exe" ← اتباع التعليمات.
  2. من ملف تم تنزيله من الإنترنت: فتح أيقونة "This PC" للوصول إلى الملف ← النقر مزدوجًا على ملف التثبيت.
  3. من ملف مضغوط: فك ضغط الملف ← النقر مزدوجًا فوق ملف التثبيت ← اتباع تعليمات التثبيت.

إلغاء تثبيت البرامج

إزالة البرنامج وملفاته من الجهاز تتم من خلال: البرنامج نفسه أو لوحة التحكم "Control Panel". أهمية إلغاء التثبيت: توفير مساحة – زيادة سرعة الجهاز.

إعداد وتثبيت الأجهزة

  • تثبيت جهاز له خاصية Plug and Play: عند توصيل الجهاز يتعرف نظام التشغيل عليه تلقائيًّا، ويقوم بتثبيت ملف البرنامج الخاص بالجهاز.
  • إذا لم يتضمن نظام التشغيل برنامج تشغيل مطابقًا للجهاز الجديد فإنه يبدأ بتشغيل برنامج المعالج للعثور عليه.

تثبيت الطابعة

الطابعة المحلية: توصيلها بمنفذ USB وستقوم خاصية التوصيل والتشغيل بعملية التثبيت تلقائيًّا. وغير الداعمة للتوصيل والتشغيل: Control Panel ← Hardware and Sound ← Devices and Printers ← Add a printer ← "The printer that I want isn't listed" ← "Add a local printer or network printer with manual settings" ← تحديد المنفذ (LPT / USB) ← اختيار البرنامج المتوافق مع نوع الطابعة ← إعطاء اسم للطابعة.
